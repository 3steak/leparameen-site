# 📍 Le Parameen

Site vitrine local pour **Le Parameen**, kebab à emporter situé à Paramé (Saint-Malo).

Objectif : proposer un site simple, clair et mobile-first pour :
- appeler rapidement
- voir l’itinéraire
- consulter la carte
- découvrir le lieu et les avis

---

## ⚙️ Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

---

## 🚀 Lancer le projet en local

```bash
git clone https://github.com/3steak/leparameen-site.git
cd leparameen-site

npm install
npm run dev
```

Ouvrir ensuite :

http://localhost:3000

---

## 🏗️ Build production

```bash
npm run build
npm run start
```

---

## 🎯 Objectif produit

Ce site est conçu comme une **landing page locale orientée conversion** :

- 📞 appel téléphonique prioritaire
- 📍 accès rapide à l’itinéraire
- 🍽️ consultation simple du menu
- ⭐ mise en avant des avis clients
- 📱 UX optimisée mobile

---

## 🧠 Choix techniques

- Next.js pour SSR + simplicité de déploiement
- Tailwind pour une UI rapide et maintenable
- Aucune dépendance inutile
- Données majoritairement statiques pour performance et simplicité

---

## 🎨 Direction artistique

Inspirée du lieu réel :

- façade noire et blanche
- palette chaude (ocre / terracotta)
- ambiance commerce de quartier
- design volontairement simple et lisible

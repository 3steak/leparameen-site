# Le Parameen

Site vitrine local pour un kebab a Saint-Malo, construit avec Next.js, TypeScript et Tailwind CSS.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run typecheck
```
